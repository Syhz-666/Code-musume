# 头像图标接入

用户确认第二版正头头像后，将其接入代码娘托盘与 Windows 程序图标。保留确认稿的透明背景、正面头部与水平双眼，不再重新绘图。

## 资源与实现

- 母版：`apps/pet/assets/branding/avatar.png`，512×512 RGBA。
- 专用托盘：`apps/pet/src-tauri/icons/tray-icon.png`，32×32 RGBA。Rust 在启动时解码为 Tauri 图像，保留彩色，不使用模板图标。
- Windows 程序图标：`apps/pet/src-tauri/icons/icon.ico`，含 16、20、24、32、40、48、64、128、256 像素帧。
- 同步常用 PNG 图标尺寸；现有 Tauri 配置已指向此 ICO。
- 打包工具：`python tools/build-app-icons.py --install`。核对 ICO 每一帧与母版缩放的像素一致，并核对透明通道。

原图、提示词、大小预览与打包校验记录保存在 `artifacts/design/icon-candidates/tray-avatar-v2-upright/`。首次替换前的资源备份位于 `artifacts/design/backups/icons-before-avatar-2026-10-29/`。母版进入源码目录，可独立重建，不依赖被忽略的设计归档。

## 验证

- 九种 ICO 帧及 PNG 透明通道校验通过；已审阅浅色、深色背景上的 16/24/32 像素预览。
- `cargo test -p pet --lib`：11/11 通过。
- `cargo clippy -p pet --all-targets -- -D warnings`：通过。
- 独立目录的普通桌面构建通过：`target/verification/debug/pet.exe`。
- 常用入口的普通桌面构建通过：`target/debug/pet.exe`，已重新启动，并实际观察到角色和五项原生右键菜单正常显示。
- `cargo fmt --all -- --check` 与 `git diff --check` 通过。

实际托盘区域未在此次窗口截图范围内；小尺寸效果依据图标文件预览审阅，不能将桌宠窗口截图视为托盘像素验收。

首次更新常用入口时，旧实例占用 `target/debug/pet.exe`，且 Windows 拒绝代理结束该进程。用户从托盘退出旧实例后继续构建。运行中的旧实例不会因替换源码而自动获得新图标；需要重新启动更新后的程序。此次不重新打包 NSIS 安装器，既有安装包也不会自动更新。
