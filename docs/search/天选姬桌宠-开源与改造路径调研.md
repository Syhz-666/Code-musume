# 华硕天选姬桌宠 — 开源现状与改造路径调研

> 调研日期：2026-09-17
> 调研范围：官方软件现状、开源生态盘点、改造技术路径、素材与版权边界
> 说明：本文只做调查，不含代码与操作步骤。凡标注「未证实」的结论，表示未找到可靠来源。

---

## 一、结论摘要（先看这里）

1. **天选姬桌宠没有任何官方开源。** ASUS 在 GitHub 上有多个组织账号（TinkerBoard、ASUS-AICS、asus-linux-drivers、Asus-Robotics-and-AI-Center 等，共 234 个 org 命中），但**没有任何一个是桌宠、吉祥物、Live2D 或二次元形象相关**。官方桌宠是闭源免费软件。
2. **社区开源生态几乎是空白。** 全 GitHub 搜索「天选姬」，真正相关的项目只有 **1 个**：`Tonyha7/TX-Mascot-Duplication`（天选姬多开，C#，**2 star**）。Gitee 搜索「天选姬」**零结果**。
3. **所以「改造官方桌宠」只有两条路**：
   - **原地改造** —— ⚠️ **难度被严重低估了**。经实际二进制分析（详见 2.7），安装包主负载区**整体加密**（熵值 8.000 bit/byte），角色形象本身极可能就在这段加密区内。虽然壁纸/萌图/语音是散文件、萌图 JSON 结构也已破解，但**无任何公开的逆向或替换成功案例**，属于无人区。
   - **换壳重建** —— 放弃官方程序，用开源桌宠框架（DyberPet / Mate-Engine / BongoCat 等）承载天选姬素材。这是**目前唯一有成熟方法论的路**。
4. **⭐ 最重要的一条：官方公开发布过天选姬的 MMD 模型，且官方明确鼓励二创。**
   - 官方在**模之屋（aplaybox）**发布 MMD 模型：https://www.aplaybox.com/details/model/i8csS26LxrxE
   - 二周年公告原文：「**天选姬所有官方公开作品皆可用于二创**」
   - 这条渠道的存在，把「换壳重建」从「得自己搞素材」变成了「**有官方合法素材可用**」。MMD 模型可转为 VRM，从而接上 Mate-Engine 路线。
5. **动手前必须先确认手上的素材是什么格式**（Live2D `moc3` / MMD-PMX / VRM / PNG 序列帧）。这个格式决定了后面走哪条技术路线，是整件事的分岔点。官方桌宠**是否使用 Live2D 尚无证据**，从资源目录看更像 2D 图片 / 序列帧。
6. **版权是真实存在的约束，但边界比想象中宽松。** 自用改造与公开发布的边界完全不同，官方素材（MMD 模型）本身带有「禁止二次配布、禁止商用」的配布规约。详见第五节。

## 二、官方桌宠现状（已核实）

### 2.1 软件基本信息

| 项目 | 内容 |
|---|---|
| 软件名 | 天选姬 / TX Mascot（内部代号 TXMASCOT） |
| 性质 | 华硕官方免费闭源 Windows 桌面宠物 |
| 归属 | 天选（TUF Gaming）系列笔记本的随机预装/配套软件 |
| 定位 | 互动类虚拟桌面宠物 |

| 系统要求 | Windows 11 64-bit 25H2（新版）；旧版支持 Win10 |
| 下载方式 | **无独立下载页**，须进入某个天选机型的「服务支持 → 驱动程序和工具软件 → 软件程序」中查找 |

| 版本 | 日期 | 体积 |

| V2.3.1 | 2022/07/14 | 66.04 MB |

三年间体积翻了近 5 倍，说明**素材（形象、皮肤、语音、壁纸）在持续加量**。但结合 2.7 的加密发现——增量内容大概率锁在加密负载区里，**对「素材提取」并非好消息**。

### 2.3 安装包构成

下载的 zip 解压后包含两个可执行文件：

- `TX Mascot Installer.exe` — 主程序安装器
- `TXmascotGPNVcheck.exe` — 程序更新服务驱动

> ⚠️ 社区反复警告：**不要直接安装到盘符根目录**（如直接装到 `D:\`），因为其自带卸载程序可能清空整个根目录。已有多名用户报告卸载后 D 盘文件夹被删除。安装时至少新建一层文件夹。

### 2.4 安装后的目录结构（关键）

安装后，**部分资源以外置散文件形式**躺在磁盘上（这是改造的着手点）：

**程序目录** `C:\Program Files\ASUS\TX Mascot\`
- `Source\` — 壁纸资源
- `StaticImage\` — 萌图图片 + json
- `Sound\` — 闹钟 / 特色语音

**用户数据目录** `C:\Users\<用户名>\AppData\Local\ASUS\TX Mascot\`
- `Wallpaper\` — 壁纸
- `MemeGenerator\` — 萌图生成器素材
- `Character\` — **天选姬「角色档案」图片**，不是模型文件

> ⚠️ **修正一个容易误判的点**：`Character\` 这个目录名看着像「换形象入口」，但实际解包出来的内容是 `TX-001-2.jpg`、`TX-002-1~4.jpg`、`TX-101.jpg` 这类**角色档案立绘（jpg 图片）**，属于「角色档案」功能页的展示图，**不是 Live2D 模型、不是可换的角色资源**。别在这里浪费时间。

### 2.5 已知的交互能力（改造时可参考的功能面）

- **键盘**：`←/→` 左右行走，`↑` 站起，`↓` 坐下，`O/P` 切换静态形象，`E` 随机萌图
- **鼠标**：拖拽、左键点击触发文字互动、鼠标碰撞触发动作表情
- **右键菜单**：调节大小比例、简易模式、最小化到托盘、设置壁纸与表情包
- **系统状态**：CPU / 内存 / 硬盘 / 网络 / 电量
- **其它**：闹钟、内置小游戏、萌图编辑生成器、角色档案、免费皮肤更新

### 2.6 唯一的社区开源项目

**`Tonyha7/TX-Mascot-Duplication`**（华硕天选姬多开）
- https://github.com/Tonyha7/TX-Mascot-Duplication
- C# / WinForms，LGPL-3.0，2 star，2022-09-10 创建，2 次提交
- 功能：README 全文只有一句「**启动时带上参数 `/duplicate` 即可**」
- **价值**：这是目前唯一的公开技术线索，证明官方桌宠**接受命令行参数**。顺着这条线，理论上可能存在其它未公开参数或配置文件，但**无人继续挖掘**。
- **源码级确证**（读其 `Form1.cs`）：核心只有一行 `System.Diagnostics.Process.Start(textBox1.Text, "/duplicate")`，确证 `/duplicate` 是**桌宠自身支持**的参数（用于绕过单实例互斥锁），并确证主程序路径为 `C:\Program Files\ASUS\TX Mascot\TX Mascot.exe`。

### 2.7 技术内构（一手二进制分析结果）

> 以下为对官方安装包 `TXMascot_ASUS_Z_V4.1.4_16667_2.exe`（250,804,144 字节）的实际解析结果，属一手证据。
> 直接下载地址：`https://dlcdnets.asus.com/pub/ASUS/GamingNB/Image/Software/SoftwareandUtility/16667/TXMascot_ASUS_Z_V4.1.4_16667_2.exe`

**① 安装器本体是 ASUS 自研套壳**
- 版本信息（明文可读）：ProductName=`TX Mascot`，ASUSTeK，4.1.4.0
- PDB 泄露路径：`D:\bios\workspace\IMG_AUTO_ExeInstaller\ASUSInstaller_Setup\Setup\x64\Release\Setup.pdb`
- 内含一个 LZMA1 压缩的 .NET Framework 4.7.2 工具 `AsusInstallerBI.exe`（解压后 8.5 MB），带 ASUS 埋点逻辑（`BusinessIntelligenceCollection`、查询 `Win32_PnpEntity WHERE DeviceID LIKE '%ASUS2018%'`）
- 内嵌 **Inno Setup 6.1.0** 标识

**② 主负载区整体加密（这是原地改造的头号障碍）**
- 约 9 MB – 212 MB 区段**熵值 8.000 bit/byte**，且找不到任何 LZMA1/LZMA2/zlib/bzip2/zstd 可解流
- → 基本可判定为**加密或私有封装**。想改包内文件，得先破封装
- → **天选姬的形象资源极可能就在这段加密区内**

**③ 但负载尾段有一段未加密 ZIP**（212–245 MB），已提取出全部 126 个条目，包括：
- `Meme_1..57.json` + 对应 `.png`
- `Basic_1/Meme_28..57.*`
- `Character_1/TX-001-2.jpg`、`TX-002-1..4.jpg`、`TX-101.jpg`
- `Gift-001..006(-200).png`
- `References/System.Runtime.WindowsRuntime.dll`、`HelperProcess.exe`

**④ 萌图 JSON 结构已破解**（解压出的原文）：
```json
{"FileName":"Meme_10.png","BackgroundColor":"#00000000",
 "TextBlockDataList":[{"Text":"…","FontColor":"#FFFFFFFF",
 "TextOutlineColor":"#FFFF9D00","BlockRect":"136.66,192,100,50"}]}
```
→ 这是**目前唯一确认可直接改写的文件格式**（改文案 / 颜色 / 坐标）

**⑤ 技术栈判断：.NET / C#（WinRT/WPF 一脉）** —— *推测，非确证*
- 依据：`References/` + `System.Runtime.WindowsRuntime.dll` + `HelperProcess.exe` + 全 PascalCase 序列化 + `TextBlock`（WPF 控件名）
- **可确证排除的**：没找到任何 Unity / Electron / Live2D 的明文证据（无 `UnityPlayer`、`libcef`、`app.asar`、`moc3`、`model3.json`、`Cubism` 字样）
- 旁证：V1.0 仅 21.76 MB，Unity 应用不可能这么小
- ⚠️ 注意：**负载加密意味着「没找到」不等于「不存在」**

### 2.8 皮肤机制（澄清一个常见误解）

「免费皮肤更新」是在**应用内**完成的（主菜单 → 设定 → 切换主题 / 下载官方扩展包 → 重启生效），**不是本地换文件**。

- 未找到任何皮肤包的文件格式说明
- 未找到任何替换成功的公开案例

### 3.2 可直接复用的开源桌宠框架（这是真正的出路）

既然官方程序改不动，那就**换壳**——用成熟开源框架承载天选姬素材。按素材格式分路线：

#### 路线 A：素材是 VRM 3D 模型 → **Mate-Engine**
- https://github.com/shinyflvre/Mate-Engine ｜ 3.7k star
- **VRM 是一等公民**：右键/M 打开设置即可换任意 `.vrm`，支持自定义 shader、动画 mod、`.ME` 格式
- 许可证：**AGPL-3.0 + MateProv2 混合许可**；⚠️ 默认角色模型为第三方版权（Yorshka Shop），**禁止再分发**
- 平台：Windows（另有非官方 Linux 移植）
- GitHub 版永久免费；Steam 版 $3.99 解锁创意工坊、事件消息、自动更新
- **改造自由度最高**，因为可以改源码（AGPL）

#### 路线 B：素材是 PNG 序列帧 / 立绘 → **DyberPet**
- https://github.com/ChaozhongLiu/DyberPet ｜ 976 star ｜ GPL-3.0
- 格式：**PNG 序列帧 + JSON**，不支持 Live2D/VRM
- **角色包规范最完善**：`res/role/<名字>/` 下放 `act_conf.json`、`pet_conf.json`、`action/*.png`
- **最低只需 default / drag / fall 三个动作**，其余自动回退
- 全程改 JSON + 放图，**不需要写代码** —— 这是所有方案里上手门槛最低的
- 有 `DyberPet_GenshinImpact` 等成熟角色包可照抄（注意该仓库已停止维护，官方建议直接把角色文件夹迁移到新版）
- 平台：Windows 打包 exe；macOS 仅源码且只开源到 v0.6.7

#### 路线 C：素材是 Live2D `moc3` → **BongoCat** 或 Live2DViewerEX
- **BongoCat** https://github.com/ayangweb/BongoCat ｜ **23.3k star** ｜ **MIT** —— 本次调研中 star 最高、许可证最干净的项目，Live2D 方案，README 称支持导入自定义模型，跨 Win/mac/Linux。（模型包的具体结构来自第三方教程，**未证实**）
- **Live2DViewerEX** — Steam **$4.99 闭源付费**，支持导入 + 创意工坊，生态最大，**零改造自由度**，只是播放器

#### 其它可选

| 项目 | 许可证 | star | 格式 | 备注 |
|---|---|---|---|---|
| LorisYounger/VPet | Apache-2.0 | 6.8k | PNG 序列帧为主 | 创意工坊 + ModMaker，WPF/Win 独占，Live2D 需写插件 |
| Zao-chen/ZcChat | GPL-3.0 | 563 | Galgame 立绘 PNG | 已重制迁移至 ZcChat2 |
| Shimeji-ee | New BSD | — | PNG 序列帧 + XML 行为 | 经典老牌，生态稳定 |
| isHarryh/Ark-Pets | GPL-3.0 | 1.1k | **Spine 3.8 且绑定明日方舟** | ❌ 天选姬素材无法落地 |
| OpenPetsHQ/openpets | MIT | 1.2k | 形象格式未证实 | 强项是插件 SDK，非形象 |
| OpenBMB/MiniCPM-Desk-Pet | AGPL-3.0 | 484 | 「角色」= LoRA 人设 | ❌ 不是形象模型 |

#### ⚠️ Live2D 的额外授权约束（走路线 C 必须知道）

Live2D **不是全开源体系**：Cubism SDK 组件适用 Live2D Open Software License，但 **Cubism Core 适用 Live2D Proprietary Software License**——**年营收超过 1000 万日元需要签 Release License**。个人自用无碍，商业化要评估。

## 四、改造路径总览

### 4.1 推荐主路径：官方 MMD 模型 → VRM → Mate-Engine

这是本次调研**最推荐的路线**，因为它同时满足「素材合法」「形象保真」「可改造」三点：

```
官方 MMD 模型（模之屋公开发布，官方鼓励二创）
        ↓  转换 MMD(PMX) → VRM
      VRM 模型
        ↓  放入
   Mate-Engine（AGPL，可改源码）
        ↓
   你的天选姬桌宠
```

- **素材合法性**：MMD 模型是官方主动发布供二创使用的，不是提取或破解来的
- **形象保真**：3D 模型，比 2D 序列帧更接近「活的天选姬」
- **改造自由度**：Mate-Engine 是 AGPL，可以改源码加功能
- ⚠️ **约束**：官方模型自带「禁止二次配布、禁止商用」规约，**自己转换自己用可以，转发模型文件不行**

### 4.2 按素材格式分路线

```
                    ┌─ 先确认手上的素材格式 ─┐
                    │                        │
        Live2D moc3 │      MMD / VRM         │      PNG 序列帧
                    ↓                        ↓            ↓
            BongoCat / Live2DViewerEX   Mate-Engine   DyberPet
              (MIT / 付费闭源)          (AGPL, 自由度最高) (GPL, 最省事)
```

> 若手上没有 MMD 模型、也不想折腾 3D，**DyberPet 仍是最省事的选择**——把官方立绘切成 PNG 序列帧即可，只改 JSON 不写代码。

**关于「原地改造官方程序」这条路的判断：**

- ✅ **有利条件**：
  - 部分资源外置为散文件（`Wallpaper` / `Sound` / `StaticImage`）
  - 程序接受命令行参数（`/duplicate` 已源码级确证）
  - **萌图 JSON 结构已知且疑似可直接改写**（改文案 / 颜色 / 坐标）——这是唯一确认可改的格式
- ❌ **不利条件**：
  - **安装包主负载区整体加密**（熵值 8.000），形象资源极可能锁在里面
  - `Character\` 只是角色档案 jpg，不是可换的模型
  - 「皮肤」是官方应用内机制，不走本地文件
  - 是否有完整性校验未知
  - **零公开成功案例**
- **建议的试水顺序**（若要探索）：
  1. 先只改 `%LocalAppData%` 与 `Program Files` 下的**散文件**（成本最低、可回滚）
  2. 再考虑改萌图 JSON（结构已知）
  3. 最后才考虑对 `TX Mascot.exe` 做反汇编 / 内存补丁级别的改造（破加密封装）
- **结论**：原地改造属于**无人区探索**。前两步风险可控但能改的只是边角（壁纸、萌图、语音）；**真正想换形象，就必须面对加密负载**。除非你愿意投入逆向，否则建议走「换壳重建」

### 5.2 官方对二创的态度：**明确鼓励**

华硕连续多年举办天选姬二创大赛，这是判断「能不能做」的关键背景：

- **二周年（2022）**二创激励计划，公告原文：「**天选姬所有官方公开作品皆可用于二创**」
- 四周年（2024）、五周年（2025）、六周年（2026）持续办赛
- 六周年规则要点：必须**原创且首次公开**、禁止抄袭盗用、不得拉踩或露出其他笔记本品牌、不得诋毁丑化天选姬、AI 作品须标注
- 官方并提供 MMD 模型与单曲伴奏作为二创素材

### 5.3 法律边界

**著作权归属**：天选姬是**华硕电脑（上海）有限公司**旗下天选品牌的虚拟偶像 IP。原始画师身份、作品属职务作品还是委托作品——**未找到可靠来源**，不做推测。角色形象作为美术作品受《著作权法》保护，提取模型/贴图涉及复制权。

**《著作权法》第 24 条第 1 款第(一)项**——「为个人学习、研究或者欣赏，使用他人已经发表的作品」可不经许可、不付酬，但须同时满足：作品已发表、**复制件来源合法**、限于个人及家庭范围、指明作者、不影响作品正常使用且不损害权利人合法权益。

**《计算机软件保护条例》第 17 条**——为学习研究软件内含设计思想和原理，通过安装、显示、传输或存储等方式使用软件的，可不经许可、不付酬。（条文本身未出现"反向工程"字样）

> 关键争议点：**「来源合法」是学界与实务的共识性前提**。若获取途径绕过技术措施，合理使用抗辩空间明显收窄。这是**学者与实务观点，非成文规定**。

### 5.4 厂商条款（注意：这是合同义务，不是法律）

### 5.5 风险分层

| 场景 | 法律定性 | 风险 |
|---|---|---|
| 纯本地自用、不传播 | 可能落入第 24 条合理使用；但可能违反 EULA | 民事风险很低；**合同违约风险存在**；若绕过加密则性质变化 |
| 发 GitHub / B站 | 落入第 53 条「复制、发行、通过信息网络向公众传播」 | 显著升高，尤其**同时分发官方模型/贴图文件**时 |
| 营利 + 情节严重 | 可能触及《刑法》第 217 条侵犯著作权罪 | 参考入罪量级：违法所得 3 万 / 非法经营 5 万 / 传播 500 件 / 下载 1 万次 / 点击 10 万次 |

**社区惯例**：模之屋 / MMD 圈通行规则是**禁止二次配布、禁止商用、公开使用须署名**。分发官方模型文件通常违反该惯例。

**推测（非结论）**：仅发布自己编写的改造代码 / 补丁、**不附带任何官方美术资源文件**，风险明显低于打包分发模型与贴图。
