## 0. 一句话结论

**存在。** 这是一个已成型、竞争密集、且平台方已亲自下场的赛道（半年内 40+ 个项目入场）。
按我们的产品定义逐条对照：**除「同一个角色随所运行的 agent 做多形态变化」一格仍无人占据外，其余每个要素都已有占位者**——其中「多 agent 支持」已是及格线，「原创形象」已被免费画廊商品化，「状态反应」人人都有。

## 4. 五个趋势（对定位的硬约束）

1. **平台方亲自下场**：OpenAI（Codex Pets）、Anthropic（claude-desktop-buddy 硬件）、DeepSeek（dsh-pet 生态）、国产 IDE（智码 AICoder 内建，○）→ 单点功能随时可能被原生功能吃掉
2. **宠物分发层出现**：Codex 精灵图格式成为事实上标准，petdex / codexpet.top 提供免费画廊 →「换形象」已从「能力」变成「基础设施」
3. **同质化 + 复刻成本≈0**：40+ 项目功能高度雷同；cc-haha（14.9k★）与 MiniCPM-Desk-Pet 均**基于 clawd-on-desk 二次开发**
4. **权限审批是少数人的深水区**：做到完整闭环的寥寥（clawd 最全），其余大多只有通知
5. **商业化被免费供给堵死**：无付费订阅成功例；免费画廊（素材 CC BY-NC 4.0）压制皮肤付费；唯一商业样本 DeskFamiliar（Steam，F2P + 外观 DLC，○）

## 5. 对「我们的差异化」的裁决

| 原设想 | 裁决 | 说明 |
|---|---|---|
| 多 agent hook 支持 | ⛔ **划掉** | 及格线；连国产 agent 全家桶都已被 clawd 覆盖 |
| 「多 agent 适配层」 | ⛔ 划掉 | 已有小项目在做（UniPet / OpenPets） |
| 原创形象 | ⚠️ **降级为「必要但不独特」** | 人人都能有；只能当「产品身份」运营，不能当壁垒 |
| 状态反应 / 权限审批 | ⛔ 商品化（审批尚有工程缺口可补） | 作 v1 功能没问题，作卖点不行 |
| **同一角色随 agent 多形态** | 🟡 **唯一空着的表达位** | 但门槛低 + 需求存疑（见 §2 注） |
| **陪伴感** | 🟢 **没人做成** | 空着的原因也可能是「难」或「没需求」——诚实标注两种可能 |

> **A 路调研的点名判断**：「**同一角色多形态 + 陪伴感**」是本次调研里确实没有对手的组合。

## 6. 残留不确定（重要几条，勿当事实）

- HermesPet 具体宠物清单、Vibe Pet 每卡是否不同角色：二手未证实
- ClawMate（npm）被描述为「按 Agent 单独配置角色」：仅线索，建议后续核实
- Codex Pets 界面细节：多源二手（存在性已被格式兼容性旁证）
- DeskFamiliar、智码 AICoder 桌宠、《林离》29 天停服等：均二手
- 中文生态：本次检索覆盖有限（搜索工具偏美国区）——**「未找到」≠「不存在」**

## 7. 对决策的含义（选项陈列，不替用户决定）

1. **若目标是「找一个市场空白」**：本次调研**没有发现低风险的空白**。最接近的空位（同一角色多形态 + 陪伴感）无人占据的原因有两种可能——没人想到，或没人要。无证据支持前者显著优于后者。
2. **若目标是「要这个功能本身」**（自己的角色反映自己的 agent 活动）：**现成方案已成熟**——clawd-on-desk 自定义主题（1 SVG + 7 GIF 起步、有脚手架与校验器），或按 Codex 宠物包格式做一个自己的角色接入任意宿主。**自研与现成的成本差距巨大且仍在拉大。**
3. **若仍要自研**，调研给出的可锚定处：① 陪伴感（唯一没人做成的）；② 同一角色多形态（唯一空着的表达位）；③ 「个人尺度的小而美」：不争市场，用现成格式规范承载自己的角色，先服务自己和身边人。
4. **待用户决定**：继续 / 重定位 / 试用现成 / 暂停；以及悬而未决的「形态（单角色 vs 平台）」与「受众」两问。
