## Phase 2 — 通路（hook → 桌宠 → 状态）

顺序：protocol 包(类型+fixtures) → Rust 壳 runtime/server/auth（curl 可验证）→ CLI 信封/HTTP → CLI `emit-fixture` → TS ingest/adapters → state 层+测试 → CLI install/uninstall/status（**先在测试项目级练**）。
- **CLI 红线实现**：hook 模式任何路径 exit 0（panic hook 静默 + catch_unwind）；绝不 println（只 eprintln 且 debug 开关）；connect+write+read 预算 ~300ms；`payload` 是**字符串原样**（最易漂移处，双向对拍）；`--dump <path>` 写文件采集；`--runtime dev` 走 dev 文件。
- **install（R8）**：解析失败拒绝写 → **先按文件名匹配移除自身旧条目**（识别=`code-musume-hook`，不用自定义字段）→ dry-run diff → 备份 → 原子写 → **自检**（用 args exec 形式真跑一次）→ 记 install.json。条目形状：`{type:"command", command:<绝对路径>, args:["--agent","claude-code","--event",<事件>], async:true, timeout:5}`；**绝不生成 if**；matcher 省略；SessionEnd 不给冷启动。**P19：exec 形式 Windows 行为未核实 → 用含空格+中文路径做第一次自检实验**。
- **TS core 边界**：`pipeline.ts` 唯一 IO 编排；其余纯函数（注入 `now`）；adapter 只翻译不做决策；forms M1 直通（不提前写规则引擎）；Pixi 只消费 RenderPlan。
- **server 中间件链**：Origin 拒绝 → Bearer（常数时间）→ 64KB → 令牌桶(~200/s) → `app.emit("core://event", envelope)`。
