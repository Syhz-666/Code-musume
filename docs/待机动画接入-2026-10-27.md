# 待机动画接入 · 2026-10-27

用户确认黑边修正版可用后，将内置角色的 `idle` 从单帧替换为 243 帧、24fps 的透明待机片段，每轮 10.125 秒。其他七态仍使用原有单帧美术。三种现有形态共用这套居家睡衣素材。

## 运行时

正式文件为 `apps/pet/assets/builtin/musume.json` 与 `spritesheet.png`，Rust 与浏览器预览打包同一份内容。正常启动无需视频文件、WorkBuddy、视频模型、Python 或制作目录。

为保持每张纹理不超过既有 4096×4096 限制，图集改为 16 列 × 16 行，单格 192×208，总尺寸 3072×3328，文件约 6.8 MB。桌宠显示尺寸仍为 144×156。待机帧占编号 0–242，其他状态占 243–249；其余空格透明。

`Clip.column` 默认为 0，旧角色包可继续加载。`row` 与 `column` 指定起始格，后续帧跨列后进入下一行。导入校验检查动作完整范围、最大帧数和图集边界。Pixi 和 DOM 兼容模式使用相同的坐标计算。

待机动画沿用现有真实状态/手动预览选择规则。“减少动画”显示首帧。仅改变表现层素材与图集读取方式，不为动画播放创建 Agent 工作事件。形态共用同一图片时复用已解码纹理，避免切换 Agent 时重复加载大图集。

## 制作与重建

已确认的源帧：`artifacts/design/preprocessed/frames/workbuddy-idle-cutout-v2/frames/`。

通过 `tools/build-idle-atlas.py` 打包。全部待机帧使用同一个缩放比例与脚底锚点，不逐帧缩放或重新居中。原七态从原静态图集统一缩小采样，姿态、表情和选态逻辑保持原意。

```powershell
python tools/build-state-artwork.py
python tools/build-idle-atlas.py --install
```

第一个命令仅重建静态输入。旧脚本的 `--install` 会拒绝覆盖已包含动画的包，避免静态 PNG 与新清单不匹配。打包报告与实际显示尺寸的亮暗底预览在 `artifacts/design/preprocessed/frames/runtime-idle-v1/`。

用户认可的原视频首尾并非逐像素相同；本次采用该片段循环，不宣称制作了新的无缝过渡。
