# 项目方案 — 2026-10-14

> 现行方案；取代 2026-10-09 版本。依据本次用户确认：工作联动优先、轻量陪伴、Rust 常驻核心、首版 Codex 角色导入，以及 Claude Code + 本机 Codex 桌面双接入。

## 产品与边界

代码娘是 Windows 桌面伴侣：用原创角色展示编码工作的变化，提示需要用户处理的事项。目标为非商业作品集和开源，声音、AI 对话、权限决策、养成、插件市场、远程/云端以及跨平台后置。Codex CLI/IDE 不在首版验收范围；共享 Codex 配置可能被这些客户端加载，但不据此宣称已验证。

首版必须有：双来源真实接入、独立安装卸载、8 个显示状态、轻量陪伴、可换角色、同角色多形态、Codex 图集导入、托盘与设置、Windows 分发。角色内置「团子」为代码原创的轻量示例；正式角色外观仍为独立素材输入。

## 里程碑

|阶段|产出|出口|
|---|---|---|
|M0|规范、字段与两家接入验证|真实样本、调用形状、信任流程有证据|
|M1|共享通路 + 双 adapter + 透明窗与托盘|两家正常会话可驱动 idle / working / done；≤1 秒；窗口可重建|

|M4|素材、安装卸载、引导、自启、全屏让位、发布|新用户可安装使用卸载；资源与体验实测过关|

M1 内先 Claude、后 Codex，通路不重复实现。代码完成与验收完成分别记录；模拟事件不能替代真人会话或日用证据。当前证据见《验证记录-2026-10-14》。

## 质量与发布

目标：可见工作动画 ≥55 FPS、空闲平均 CPU ≤1.5%、相关进程专用工作集合计 ≤250MiB。按整机 CPU 容量归一化并计入 WebView 子进程；10 分钟采样。Pixi 首选，实际角色未达标时使用已实现的 DOM 兼容显示；由实测决定默认方案。

先隔离项目，后用户级接线。Codex 用户必须在 Codex 内审阅和信任定义；安装器不修改信任库。升级后重新检查。非托管 hook 的信任机制属于 Codex。

代码许可 MIT；导入素材沿用其原授权。首版静音、本地处理、无遥测；正式素材另行落实归属与许可。
