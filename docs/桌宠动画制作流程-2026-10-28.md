# 桌宠动画制作流程

这份流程以已完成的待机动画为依据，供思考及后续状态复用。工作文件放在 `artifacts/design/`；应用只打包 `apps/pet/assets/builtin/` 的正式图集和清单，不在启动时调用视频模型。

## 1. 固定角色与画布

从已确认的角色图准备参考图，禁止视频模型先重画角色。统一 1920×1080、纯绿 `#00FF00`、正面镜头、水平居中、头顶约 20%、脚底约 85%，保留至少 10% 安全边界。缩放与脚底对齐只计算一次，整段使用同一变换，不能逐帧自动裁切或重新居中。

参考图、准确提交的提示词、生成参数和原始 MP4 一起保留在 `preprocessed/source-videos/workbuddy-<状态>-vN/`。原始文件不覆盖，以便追溯质量问题。

## 2. 生成单条样片

WorkBuddy 使用帧驱动 `miora_frame_to_video`。前次实际路由接受 `768P` 或 `2K`，拒绝 `1080p`；因此提交 `2K`，后期统一采样，不反复试错。当前路由不允许首尾帧与额外参考图同时提交，也不能关闭音轨：只传首尾帧，姿势参考用文字表达；成片后删除音轨。聊天模型名称不代表视频模型。保留真实任务 ID、实际模型、尺寸、帧率与时长，费用无法确认时写“未知”，不能用估计冒充报价。

每次只生成已授权的一个状态，不满意不自动批量重抽。角色一致性、纯绿背景、相同首尾只是生成要求，必须在原片中实际检查。前次待机原片中间变为黑底、首尾不完全相同，说明不能把提示词视为质量保证。

## 3. 检查与抠图

用视频解码工具检查尺寸、帧数、时间戳及音轨；运行时不保留声音。先抽取开头、中间、眨眼、结尾等样本，确认脸、手、服装、脚底位置与动作可用，再处理全部帧。

抠图保留 RGBA PNG 母版。绿底和黑底须分别识别；保留眼睛与面部线条，检查发丝、袖子之间的封闭背景孔洞。前次采用 `tools/extract-idle-video.py` 初抠，再通过 `tools/defringe-idle-video.py` 在窄边缘修正黑底污染。后者针对白蓝头发、粉白睡衣调色，不应直接套给黑色服装。

抠完必须在白底、深底与棋盘格上检查，尤其检查眨眼时眼睛有无透明洞、头发有无黑毛边。透明预览使用无损编码，避免有损 WebP 在透明边缘重新制造脏边。查看用 MP4 含背景，不能作为透明母版。

## 4. 循环与状态衔接

持续状态分为进入、持续、退出：例如待机抬手进入思考，保持思考姿势循环，再放手返回。持续段不能反复演进入动作。生成片中的三个段落按实际动作截取，不机械相信提示词的秒数。

循环接缝必须比较最后一帧到第一帧的变化，不能只比较整段中部。进入与退出需要对齐共同站姿、角色尺寸和脚底锚点。姿势差异较大时，必须保留真实动作过程；短暂混合仅用于消除同姿势下的小幅色差或呼吸相位差，不能用长时间双影代替抬手动作。

运行时还须处理在半途换状态、连续快速切换以及返回真实状态，不能为了播完一整段而延迟真实工作信息。“减少动画”直接显示对应状态的代表静帧。手动预览不伪造工作事件或提前确认真实状态已经显示。

## 5. 打包、验证与交付

统一帧格、尺寸和脚底位置后打包图集，检查每个动作的起始格、完整帧范围、帧率及循环策略，避免超过图片尺寸和解码限制。应用与预览使用同一份正式素材。

至少检查：透明边界、绿边与黑边、循环接缝、待机与新状态双向切换、快速打断、Pixi 与兼容模式、手动预览、减少动画、刷新和窗口重建。运行类型检查、相关前后端测试和实际桌面测试，审阅截图后更新受影响视觉基准，最后重建正常 `target/debug/pet.exe`。

交付保留：原片、提示词、透明序列、可观看预览、质量报告、正式图集与清单、测试记录。记录实际完成范围，原片中尚未修复的问题不能标记为已验收。

## 工作动画验证出的替代方法

同日工作状态的10秒双帧请求在2K和768P均失败。用户要求根据反馈调整方法后，改为5秒、768P、仅首帧的简短图驱动请求成功。它只生成“站姿→抬手→保持工作”，本地取保持段循环，反向复用真实抬手作为放手退出，无需再次生成退出片段。成功方案不证明某个参数就是旧失败的唯一原因，但已可完成同一动画目标。

生成工具名是接口记录，不是角色设计要求；当前WorkBuddy的VideoGen与旧记录miora名称可能不同，使用前核对真实图片输入和当前授权范围。参数校验发生在任务创建前时按真实报错修正；任务已有ID时先核实结果，避免把取回失败误当成需要新任务。保持每次尝试和实际花费证据可追溯，不把会话总消耗冒充单条视频费。

实际768P成片1344×768为7:4，必须统一缩放补边，不能直接拉伸到1920×1080。新处理工具支持短视频采样、保比例解码及该角色配色的去绿／青色溢出。完整的成功来源、三段帧数、接入和13项桌面功能／22张视觉回归记录见[工作动画制作](工作动画制作-2026-10-29.md)。
