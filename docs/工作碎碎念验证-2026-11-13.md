在设置的「使用偏好 → 工作碎碎念设置」填入接口协议、包含版本前缀的 HTTPS 基础地址、模型、API Key 和昵称。先用固定样例测试连接，再保存并打开开关。开启后选取的可见回复和昵称会发往所选服务。会话内容留在内存，Windows 凭据管理器保存 API Key。

脱敏字段形状用于回归：

```json
{
  "codex": {
    "turnId": "example-turn", "status": "inProgress",
    "items": [{"type": "agentMessage", "id": "example-item", "phase": "commentary",
               "text": "示例进展", "completedAtMs": 1}]
  },
  "claude": {
    "type": "assistant", "isSidechain": false, "sessionId": "example-session",
    "message": {"role": "assistant", "stop_reason": "tool_use",
                "content": [{"type": "text", "text": "BAN_TEST_START"}]}
  }
}
```

Codex 探针使用本次正在工作的会话，记录结构而未保存正文。双来源同时运行、用户所选总结服务、真实模型台词和服务端缓存命中仍需实机验收。模拟服务返回的缓存统计只验证客户端读数。
