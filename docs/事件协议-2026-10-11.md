## 2. 版本与兼容

- `PROTOCOL_VERSION = 1`（对应 Envelope 的 `v` 字段）。bump 规则：**字段增删或语义变更**时 +1；新增可选字段不 bump。
- **未知字段忽略**（前后双向）：任何一侧收到不认识的字段必须忽略而非报错。
- **未知事件透传**：adapter 收到不认识的 `event` 值 → 产出 `kind="unknown"` 的 CanonEvent（附原事件名），**不得丢弃**。边界：只覆盖**已安装事件**（安装集见《状态机规范》§7.1）；未安装事件根本不会到达。
- **版本错配**：CLI 读到 runtime 文件 `v` 与自身不一致 → **主动放弃发送**（静默）。app 侧比对 `install.json` 记录的 CLI 版本与内置版本，不一致 → 角色身上给可见反馈（架构 §9.4）。
- **时间规则**（R11）：跨进程一律 **UTC epoch ms（int64）**；时长用单调时钟自算；**禁止**本地时间字符串进入协议。
- **编码**：UTF-8 无 BOM；路径字符串**原样透传不做归一化**（`\` 与 `/` 都可能出现）。

## 3. Envelope（hook CLI → 桌宠进程）

| 字段 | 类型 | 必填 | 含义 | 备注 |
|---|---|---|---|---|
| `v` | number | ✅ | 协议版本（=1） | 版本错配检测 |
| `agent` | string | ✅ | agent 标识（`"claude-code"`） | **来自 argv `--agent`**，不解析 payload |
| `event` | string | ✅ | 官方事件名原文（如 `"PreToolUse"`） | **来自 argv `--event`** |
| `ts` | int64 | ✅ | UTC epoch ms | CLI 本地时钟生成 |
| `src` | object | ✅ | `{ cli: string(semver), pid: number }` | 诊断与存活判断 |
| `payload` | string | ✅ | **stdin 原文**（不解析、不重编码） | 最易漂移处，须双侧对拍 |
| `parseError` | object？ | — | `{ kind: "read"｜"size"｜"json", detail?: string }` | 畸形 payload 的落点；有它仍发送 |

**大小上限 64 KB**：超限 → 截断 + `parseError.kind="size"`，**仍发送**（宁缺勿重）。畸形 JSON → `parseError.kind="json"`，`payload` 保留原文。

**传输约定**（本地 HTTP）：
- `POST /v1/event`：唯一写入口；`Content-Type: application/json`；`Authorization: Bearer <token>`；`Connection: close`；**不带 `Origin` 头**。
- `GET /v1/health`：只读自检（供 `status` 子命令与 E2E 用）。
- 状态码语义：`401/403` 鉴权失败；`413` 超限；`429` 限流（~200 req/s 令牌桶）。**CLI 侧对以上一律静默丢弃（exit 0）**。
- 响应体：成功返回 `{"ok":true}`；app 对事件的处理**异步**（POST 返回 ≠ 已处理）。

## 4. CanonEvent（adapter 输出，状态机输入）

### 4.1 通用字段

| 字段 | 类型 | 必填 | 含义 |
|---|---|---|---|
| `kind` | CanonKind | ✅ | 归一化事件类型（4.3 封闭枚举） |
| `agentId` | string | ✅ | 同 Envelope.agent |
| `sessionId` | string | ✅ | 会话键；缺失时用兜底 `"unknown:<pid>:<event>"` |
| `at` | int64 | ✅ | 事件时刻（UTC epoch ms，来自 Envelope.ts） |
| `tool` | object？ | — | `{ name: string, useId?: string }`（工具类事件） |
| `durationMs` | number？ | — | 工具级耗时（仅 PostToolUse/PostToolUseFailure 有；**不含权限框与 PreToolUse hook 耗时**） |
| `permissionMode` | string？ | — | `default｜plan｜acceptEdits｜auto｜dontAsk｜bypassPermissions`（**并非所有事件都带**；Manual 传 `"default"`，永不传 `"manual"`） |
| `cwd` | string？ | — | **仅内存使用**（不上屏、不落盘、不进日志——R14） |

### 4.2 逐 kind 专有字段

| kind | 专有字段 | 说明 |
|---|---|---|
| `session.start` | `source: SessionSource`、`title?: string` | — |
| `session.end` | `reason: SessionEndReason` | — |
| `prompt.submit` | —（时间标记） | 状态层在此打 `promptStartedAt` |
| `tool.activity` | （用通用 `tool`/`durationMs`） | — |
| `tool.failure` | `error?: string`、`isInterrupt?: boolean` | `is_interrupt` 语义有限（见《状态机规范》§8） |
| `permission.request` | （用通用 `tool`） | 无 `tool_use_id`（官方如此） |
| `permission.denied` | `reason?: string` | **仅 auto 模式会到达**（P7） |
| `notify.permission` / `notify.needs_input` / `notify.idle` / `notify.completed` | —（由 kind 区分类别） | 不携带 `message` 原文（R14） |
| `turn.end` | — | `last_assistant_message` **不进协议**（R14） |
| `turn.fail` | `error: StopError` | — |
| `subagent.start` / `subagent.stop` | `subagentType?: string` | 不改主状态（见状态机规范） |
| `compact.start` / `compact.end` | `trigger?: "manual"｜"auto"` | — |
| `unknown` | `rawEvent: string` | 透传兜底 |

## 5. 映射契约（AgentAdapter）

### 5.1 接口

```ts
interface AgentAdapter {
  id: string;                          // "claude-code"
  matches(e: Envelope): boolean;       // 通常 e.agent === id
  toCanon(e: Envelope): CanonEvent[];  // 0..n（一个 hook 事件可拆成多个）
  sessionKey(e: Envelope): string;     // 会话维度键（Claude Code = session_id）
}
```

adapter **只做语义翻译**：不判优先级、不决定形态、不接触时钟。总规则：**未知字段忽略、未知事件透传**；`payload` 解析失败或字段缺失一律降级，不抛异常。

### 5.2 已安装事件映射表（15）

| 官方事件 | → kind | 携带字段 | sessionId 来源 |
|---|---|---|---|
| `SessionStart` | `session.start` | `source`、可选 `session_title` | `session_id` |
| `SessionEnd` | `session.end` | `reason` | `session_id` |
| `UserPromptSubmit` | `prompt.submit` | — | `session_id` |
| `PreToolUse` | `tool.activity` | `tool{name,useId}` | `session_id` |
| `PostToolUse` | `tool.activity` | 同上 + `durationMs` | `session_id` |
| `PostToolUseFailure` | `tool.failure` | `tool`、`error?`、`isInterrupt?`、`durationMs?` | `session_id` |
| `PermissionRequest` | `permission.request` | `tool{name}`（无 useId） | `session_id` |
| `PermissionDenied` | `permission.denied` | `tool{name,useId}`、`reason?` | `session_id` |
| `Notification` | 按 `notification_type` 四拆：`permission_prompt`→`notify.permission`；`agent_needs_input`→`notify.needs_input`；`idle_prompt`→`notify.idle`；`agent_completed`→`notify.completed`；**其余 8 值 → 产 0 个 CanonEvent**（显式忽略） | — | `session_id` |
| `Stop` | `turn.end` | — | `session_id` |
| `StopFailure` | `turn.fail` | `error` | `session_id` |
| `SubagentStart` | `subagent.start` | `subagentType` | `session_id`（注：事件内另有 `agent_id`，属子代理身份，非会话键） |
| `SubagentStop` | `subagent.stop` | 同上 | `session_id` |
| `PreCompact` | `compact.start` | `trigger` | `session_id` |
| `PostCompact` | `compact.end` | `trigger` | `session_id` |

### 5.3 降级规则

| 输入情况 | 输出 |
|---|---|
| `payload` 非 JSON / 空 | `kind="unknown"`（记原始 `event`），状态机按事件名可继续工作 |
| `hook_event_name` 缺失或与 argv `event` 不符 | 以 **argv `event` 为准**（权威），照常映射 |
| 官方未知的新事件（已安装名下的未来变化） | `kind="unknown"` + `rawEvent` |
| 事件已知但关键字段缺失（如 `notification_type` 没了） | `kind="unknown"`（宁可不动，不猜） |

## 6. RenderPlan（core → 渲染层）

| 字段 | 类型 | 必填 | 含义 |
|---|---|---|---|
| `animation` | ActionKey | ✅ | 动作键（8 态一一对应 + 变体） |
| `form` | string | ✅ | 形态 id（M1 恒为 `"default"`） |
| `slots` | SlotSpec[] | ✅（可为空） | 槽位叠加（M1 恒为空） |
| `bubble` | object？ | — | `{ key: BubbleKey, params?: Record<string,string>, ttlMs?: number }` |
| `transition` | object？ | — | `{ durationMs: number, easing: "linear"｜"easeInOut" }` |
| `intensity` | number | ✅ | 0..1，表达强度（请求注意三级分层用） |
| `sfx` | string？ | — | 音效键（M1 不实现，字段先留） |

- **ActionKey 枚举**（v1）：`idle` / `thinking` / `working` / `waiting_permission` / `notification` / `done` / `error` / `sleeping`。
- **BubbleKey 枚举**（v1）：`waiting_permission` / `notification` / `done` / `error`。**只允许状态文案 key**——不得承载 prompt / 代码 / 路径 / `last_assistant_message`（R14）。
- **未知 key 降级**：渲染层必须为未知 `animation`/`bubble.key` 提供默认动作（回 `idle` 或最近已知态），**不得空白/崩溃**。
