# 事件协议 — 2026-10-14（v2）

> 现行；Rust contracts 的 serde 类型为可执行真相源。TS declarations 生成并入库，CI 重生成比较。旧 v1 未发布，整体升级，不双读。

## 传输

POST /v2/event，JSON + Bearer，成功 202 表示已入队，尚未保证显示。GET /v2/health 同样鉴权，返回版本与最新脱敏 Projection；不返回 token。

EnvelopeV2：v=2、id（唯一）、agent（claude-code/codex）、event、ts（UTC epoch ms，来源时间线索）、src（cli/pid）、payload（原始 UTF-8 字符串）、parseError（null 或 kind）。id/event 各 ≤128 字节；原始 payload ≤256KiB；序列化 body ≤2MiB。错误输入不猜身份，只进入脱敏诊断。

CanonicalEvent 为内部类型：来源/会话/turn/actor/tool ID、工具名、输入的内存哈希、事件 kind。kind 分 session、prompt、tool start/end/failed、permission/denied、notice、done/error、actor、compact 与 interrupt。CLI 不做这些语义判断。

## 来源差异

|字段/信号|Claude|Codex 桌面|
|---|---|---|
|轮次|prompt_id|turn_id|
|会话|session_id|session_id；子 agent 使用父会话|
|主体|agent_id（有则保留）|仅明确信号保留，缺失为未细分的会话活动|
|工具|tool_use_id|tool_use_id|
|权限关联|PermissionRequest 无 tool ID|PermissionRequest 无 tool ID|
|中断|信号盲区，保守降级|Interrupt|
|轮次 API 失败|StopFailure|当前 hook 无等价信号，不伪造|
|通知|官方通知四类映射|没有对应来源时不合成通知|

官方来源：code.claude.com/docs/en/hooks；learn.chatgpt.com/docs/hooks。安装基线：Claude 2.1.295，Codex 内置 0.162.0-alpha.17.2。Claude 正常只读会话已捕获 5 类真实事件；Codex 基线只代表本机版本，真实桌面验收仍待定义审阅与信任。fixture manifest 明确区分 synthetic-official 与 real-redacted。

## 显示接口

Projection：v、instanceId、revision、state、certainty、dominantAgent、sessionLabel（短哈希）、pendingCount、activeSessions、formId、characterId、bubbleKey、intensity、missedEvents、sessions 和 capabilities。完整字段类型以生成文件为准。

subscribe_projection(onUpdate, subscriptionId) 原子注册/初始快照；get_projection 拉取最新；unsubscribe_projection 仅取消当前 token。客户端拒绝同实例旧修订和退役实例的迟到帧。Config、Diagnostic、角色 manifest 和安装预览也是生成接口。

默认不把 prompt、代码、工具输入、响应、transcript、cwd 或最后消息放入持久日志和显示接口。工具输入只用于内存哈希关联；原始 payload 处理后释放。诊断保存最近 200 条事件名、短身份与处理结果。

### 2026-10-15：渲染诊断补充

业务 v2 信封与 Projection 字段保持不变。新增独立 RenderReceipt：instanceId、revision、latencyMs。桌宠通过 report_rendered(instanceId, revision) 在对应 DOM/Canvas 帧及图片解码完成后报告；宿主仅接受当前实例、已发布的新修订，并用自身单调时钟测量延迟。其他窗口、未知修订和迟到回执不影响结果。

受原鉴权保护的 /v2/health 增加 renderReceipt，可为空。该字段只用于诊断，不参与状态判断，也不代表物理显示器已扫描出画面。读取旧修订的回执不能证明新事件已显示。
