# 手动状态预览

在设置 →「角色与形态」→「手动状态预览」中开启功能，再从下拉框选择八个状态之一。桌宠底部会显示「手动预览」，设置卡片同时显示所选状态和实时工作状态。

点击「返回真实状态」会显示当前最新的工作状态，开关继续保持开启。关闭开关会结束预览并收起控件。关闭设置窗口不结束预览；重新打开后可以继续操作。开关会保存，具体的手动选择不会保存，重启代码娘始终先显示真实状态。

## 显示与工作事件

预览期间后台继续处理真实事件、待处理数量、会话和计时。手动选择不会创建工作事件，也不会清空会话。真实提示气泡仍然正常显示。

角色与形态继续采用已生效的设置。某个角色没有所选状态的素材时，沿用待机回退，并在卡片提示「缺少对应素材，当前显示待机」。开启「减少动画」时使用对应状态的第一帧。当前内置角色各状态只有一帧，后续添加多帧素材后沿用此功能。

## 接口与兼容

- `Config.manualAnimationEnabled`：默认 `false`，旧配置缺少字段时正常加载，配置版本仍为 1。
- `AnimationPreview`：`enabled`、可空的 `state`、递增的 `revision`。仅开关写入配置文件。
- `get_animation_preview`：读取宿主的预览快照。
- `set_animation_preview_enabled(enabled)`：即时保存单项偏好；关闭时清除手动选择。
- `set_animation_preview_state(state)`：选择 `DisplayState`；`null` 表示返回真实状态；关闭功能时拒绝非空选择。
- `animation-preview-changed`：向窗口广播快照。先监听再读取，按修订号过滤过期事件和命令结果。

真实 `Projection` 和 HTTP v2 协议不变。手动预览期间不为真实状态的新修订提交渲染回执；恢复真实状态后提交当前修订。宿主同时拒绝预览期间的回执，避免前端异步请求竞态。

## 验证入口

`pnpm verify` 覆盖共享类型、旧配置兼容、开关状态转换、消息顺序与原有工作逻辑。`pnpm test:ui` 使用隔离配置和真实桌面窗口，覆盖两种渲染方式、八态预览、事件继续更新、返回真实、素材缺失、刷新、关闭与重开窗口、窗口重建，以及重启后仅保留开关。

窗口重建后使用标准 WebDriver 同步端点执行宿主命令，规避 WDIO 1.5.0 按旧窗口标签缓存异步回调的问题。新增预览截图保存在测试运行目录中，既有 22 张基准保留独立审阅流程。
