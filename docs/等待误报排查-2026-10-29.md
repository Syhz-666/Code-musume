# Codex 等待误报排查

## 结论

命令已经完成，桌宠仍提示「等你处理」的一个确定原因是权限请求与工具完成事件的输入匹配错误。当前 Codex 桌面内置运行时为 `0.165.0-alpha.1.2`：Bash 的权限事件比开始／完成事件多带一个审批说明 `tool_input.description`，且没有 `tool_use_id`。旧适配器把完整输入作为摘要，导致同一命令在两边得到不同的摘要，不能解除等待。

此缺陷已修复：只对 Codex 的规范 Bash 输入，在有字符串 `command` 时从身份摘要中排除审批说明。不同命令仍不能互相解除等待；其他工具、Claude、会话和并发歧义继续使用原有严格关联规则。v2 信封、Projection 和前端状态规则没有改变。

审批请求也可能由自动流程批准，不等同于聊天里出现需要用户回答的问题。官方字段说明见 [Codex hooks](https://learn.chatgpt.com/docs/hooks)。当前仍依据工具完成或轮次结束等信号解除等待；缺少独立「审批已放行」事件时，正在审批／执行的长工具仍可能短暂保持等待，这次没有用计时器猜测审批结果。
