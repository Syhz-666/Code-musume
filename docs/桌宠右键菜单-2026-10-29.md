# 桌宠右键菜单

按用户要求，桌宠不再显示常驻的「退出」和齿轮按钮。左键拖动与角色反馈沿用原有行为；右键角色或桌宠窗口内空白区域，弹出与托盘相同的系统菜单：显示、隐藏、切换点击穿透、设置与接入、退出。Esc 可以取消菜单。

设置页右上角的「退出代码娘」保留。开启点击穿透或隐藏角色后，通过托盘菜单恢复或退出。关闭设置窗口仅关闭设置，不退出桌宠。

## 实现

前端只发送右键位置，Rust 使用 Tauri 原生 `Menu` 弹出菜单，桌宠与托盘共用同一个菜单和事件处理入口。位置使用逻辑像素，菜单由 Windows 排布，不受 160×210 的 WebView 内容范围裁剪。没有扩大透明窗口，也没有修改工作事件、状态规则或动画播放。

没有给生产版本增加测试权限。`show_pet_menu` 只接受桌宠窗口调用，并拒绝非有限数值的位置。菜单打开失败会显示托盘操作提示。前端防止同一次菜单交互重复打开，取消或选择后允许再次打开。
