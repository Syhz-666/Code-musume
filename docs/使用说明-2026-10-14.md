# 代码娘 0.1.0 使用说明

这是 Windows 工程试用版。Claude 正常流程已经真实验证，Codex 桌面接入还需要在原应用内完成定义审阅与信任；完整工作日体验仍在验收中。

## 启动

安装版从开始菜单打开 code-musume。便携版先解压整个文件夹，再打开 code-musume.exe；让 code-musume-hook.exe 保持在同一个文件夹。

角色常驻右侧，默认手动启动、静音。拖动角色可移动位置，点击齿轮打开设置。托盘菜单提供显示、隐藏、鼠标穿透、设置与退出。开启穿透后，从托盘切回即可再次触摸或拖动。

## 接入工作

1. 打开「设置与接入」，先选择一个隔离测试项目。
2. 在 Claude Code 或 Codex 桌面卡片中点击安装预览，检查目标文件后确认写入。
3. Claude 在受信任项目中新开会话；Codex 在桌面应用中按其提示审阅并信任 hook 定义，再开始本机任务。定义变更或升级后重新检查信任。
4. 让 agent 做一项小任务，观察思考、工作与轮次结束提示。接收情况可在诊断页查看。
5. 隔离项目验证正常后，再按需要切到用户范围接入。

两家的安装和移除独立操作。需要授权或输入时，在原 agent 应用中处理，代码娘负责提示。长时间没有新事件时，提示会减弱，诊断页可清理旧状态并等待新事件。

首版 Codex 的验收范围是桌面应用里的本机任务。CLI、IDE、远程或云端任务的表现仍需后续验证。

## 角色与显示

角色页可以选择内置团子、自动随 agent 换形态、为某一 agent 指定形态，或锁定一个形态。导入支持原生角色文件夹，以及已核实布局的 Codex PNG/WebP 图集。导入会复制素材并保留已有授权信息。

偏好页可设置减少动画、全屏让位、隐藏和开机启动；默认不开机启动。角色在空闲时有轻量动作，触摸反馈有冷却时间，需要处理的工作提示优先显示。

## 检查连接

若角色没有变化，先确认代码娘正在运行，接线范围与正在工作的项目一致，再检查来源应用的信任提示。诊断页只展示事件名称、处理结果和短身份，不保存提示词或代码。

轮次结束气泡持续约 3 秒，随后恢复仍在进行的其他活动。应用整体退出后，运行状态不保存；重启后等待新的工作事件。

## 移除

设置页可以分别预览移除 Claude 或 Codex 接线。安装版卸载器会清理本版本登记的接线与自启项；后来新增的其他配置应保留。便携版先从设置页移除接线，再退出并删除解压目录。

代码和内置程序绘制示例采用 MIT；导入素材沿用原授权。项目当前方案与验证记录可在源码仓库的 docs 目录查看。
